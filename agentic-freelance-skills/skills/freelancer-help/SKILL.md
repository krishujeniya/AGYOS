## Agent Guidelines & Workflows

### 1. Navigating the Repository
When a user asks how to start or where to find resources:
- Reference [09A-ECOSYSTEM-GUIDE.md](references/09A-ECOSYSTEM-GUIDE.md) to explain the 9-module system and map their current business challenge to the correct skill folder.
- Provide them with the standard Agentic Trigger prompt to copy-paste.

### 2. Demonstrating the Skills in Action
When a user asks for a realistic demonstration of how these skills work in practice:
- Reference [09B-END-TO-END-EXAMPLE.md](references/09B-END-TO-END-EXAMPLE.md) to showcase the story of Aria, an AI/ML Freelancer.
- Highlight the exact transition points: how client acquisition leads to sales closing, which triggers legal contracts, which flows into project kickoff, and how scope creep is defended using the emergency kit.

### 3. Explaining Career & Lifestyle Benefits
When a user is overwhelmed, doubts their rates, or struggles with burnout:
- Reference [09C-FREELANCE-LIFE-IMPACT.md](references/09C-FREELANCE-LIFE-IMPACT.md) to present the "Before vs. After" comparison.
- Walk through the time savings breakdown showing how automating administration and templating development saves up to 15+ hours per week.
- Discuss boundaries and financial runway planning as tools for emotional sanity.
