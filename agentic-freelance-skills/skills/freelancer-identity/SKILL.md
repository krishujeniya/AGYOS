## Agent Guidelines & Workflows

### 1. Personal Branding
When asked to define a freelancer's brand or positioning:
- Reference [01A-PERSONAL-BRAND.md](references/01A-PERSONAL-BRAND.md) to audit their **Trust Triangle** (Competence, Credibility, Reliability).
- Help them construct a formal **Brand Promise Statement**: *"I help [ideal client] achieve [specific outcome] through [unique mechanism]."*
- Define their **Anti-Positioning** boundaries (what they do *not* do) to clarify expertise and shield against scope creep.

### 2. LinkedIn Profile Optimization
When asked to write or improve a LinkedIn profile:
- Reference [01B-LINKEDIN-OPTIMIZATION.md](references/01B-LINKEDIN-OPTIMIZATION.md) to apply the **7-Second Profile Test**.
- Write a 220-character headline following the formula: `[Role / Core Niche] + [Outcome / High-Value Result] + [Trust Anchor / Proof] + [Call to Action]`.
- Structure the About section with hook-driven narrative copywriting, value pillars, and a clear call to action.
- Guide them through the **15-15-15 outbound prospecting ritual** (15 DMs, 15 Comments, 15 Connections daily).

### 3. Portfolio Case Studies
When asked to write a case study or design a portfolio page:
- Reference [01C-PORTFOLIO-POSITIONING.md](references/01C-PORTFOLIO-POSITIONING.md) to structure projects using the **STAR-M Case Study Template** (Situation, Task, Action, Result, Metrics).
- Ensure case studies emphasize business outcomes and hard metrics (revenue, speed, accuracy) over tutorial-style descriptions.
- Set up a three-tiered **Good-Better-Best service matrix** (Starter, Professional, Enterprise) to maximize project deal size.
