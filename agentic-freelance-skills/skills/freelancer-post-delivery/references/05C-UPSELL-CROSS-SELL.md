## 1. The Revenue Expansion Framework

### The 4 Types of Revenue Expansion

| Type | Definition | Example | Difficulty |
|------|------------|---------|------------|
| **Upsell** | More of the same service | Bigger model, more features, higher tier | Easy |
| **Cross-Sell** | Different but related service | SEO after web dev, ads after copywriting | Medium |
| **Deepen** | More strategic involvement | From execution to advisory | Medium |
| **Expand** | Same service, new department/team | Roll out to other teams | Hard |

### The Math

| Metric | Value |
|--------|-------|
| **Cost to acquire new client** | $500-$2,000 |
| **Cost to upsell existing client** | $50-$200 |
| **Probability of upsell success** | 60-70% |
| **Probability of new client close** | 10-20% |
| **Average upsell value** | 30-50% of original project |

**Conclusion:** Upselling is 10x more efficient than new client acquisition.

## 4. The Upsell Conversation

### The Natural Upsell Framework

```
1. ACKNOWLEDGE current success
   "The churn model is predicting with 89% accuracy..."

2. IDENTIFY adjacent opportunity
   "...and I noticed your LTV data is clean enough to add 
    a customer segmentation model"

3. QUANTIFY the added value
   "This would let you personalize onboarding, which typically 
    improves activation by 15-20%"

4. MAKE IT EASY
   "Since the data pipeline is already built, this would only 
    take 2 weeks and $3,000"

5. ASK FOR THE NEXT STEP
   "Worth exploring in our next check-in?"
```

### The "While We're At It" Upsell (At Delivery)

```
"As we're wrapping up [project], I noticed something that could 
add significant value with minimal extra work.

Since I've already built [infrastructure/pipeline], adding 
[feature] would only take [X] hours but give you [Y benefit].

It would mean [specific outcome], and since I'm already deep 
in the codebase, I can do it for $[Amount] instead of the 
usual $[Higher Amount].

Interested? If not, no worries — just thought I'd mention it 
while I'm here."
```

### The Data-Driven Upsell (At 30-90 Days)

```
"I've been reviewing [system] performance over the last [period], 
and the data shows something interesting:

[Metric 1] is performing at [X]%, but [Metric 2] has room for 
improvement. 

If we added [enhancement], I estimate we could improve 
[Metric 2] by [Y]%, which translates to approximately 
$[Value] in [revenue/savings].

The investment would be $[Amount] and [timeline]. 
Worth discussing?"
```

### The Strategic Upsell (Quarterly)

```
"As we plan for [next quarter], I wanted to share an observation:

[Client's competitors/industry] are increasingly investing in 
[capability]. Based on your roadmap, this aligns with your 
goal of [objective].

I can help you get ahead by [specific approach]. This would 
position you as [competitive advantage].

Shall we include this in the Q[Number] plan?"
```

## 5. Productized Services

### What is Productization?

Turning custom work into repeatable, packaged services:

| Custom Work | Productized Version | Price |
|-----------|---------------------|-------|
| "I'll build you a churn model" | "Churn Prediction in a Box" — 2-week delivery, fixed scope | $5,000 |
| "I'll audit your AI system" | "AI Health Check" — 1-week assessment, standard report | $1,500 |
| "I'll train your team" | "MLOps Bootcamp" — 2-day workshop, standard curriculum | $3,000 |
| "I'll optimize your pipeline" | "Pipeline Performance Tune-Up" — 3-day optimization | $2,500 |

### Benefits of Productization

| Benefit | Impact |
|---------|--------|
| **Predictable pricing** | Clients know exactly what they get |
| **Faster sales** | No custom scoping for every project |
| **Higher margins** | Repeatable = efficient |
| **Easier marketing** | Clear value proposition |
| **Scalable** | Can train others to deliver |

### Productized Service Template

```markdown
# [Service Name]

## The Problem
[Target client] is struggling with [specific pain], which costs 
them approximately [quantified cost] per [time period].

## The Solution
In [timeframe], I will [specific deliverable] that [specific outcome].

## What's Included
• [Deliverable 1]
• [Deliverable 2]
• [Deliverable 3]
• [Deliverable 4]

## What's NOT Included
• [Excluded 1]
• [Excluded 2]

## The Investment
**$[Amount]** — Fixed price, delivered in [timeframe]

## The Guarantee
If [specific condition], I will [remedy].

## Next Step
Book a 15-min call to see if this is right for you: [Calendly link]
```

## 6. AI Prompts

### Prompt 1: Upsell Opportunity Finder

```
Act as a growth strategist for freelance services.

Current client project:
- What we built: [DESCRIPTION]
- Client's business: [TYPE]
- Their current metrics: [NUMBERS]
- Their stated goals: [OBJECTIVES]
- Their tech stack: [TOOLS]

Identify 3 natural upsell opportunities:
1. Immediate (can add to current project)
2. Near-term (30-60 days post-launch)
3. Strategic (next quarter)

For each:
- The opportunity
- Why it fits their goals
- Estimated value to them
- Your price
- How to introduce it (script opening)
```

### Prompt 2: Cross-Sell Matrix Builder

```
Act as a service expansion strategist.

My core services:
1. [Service A]
2. [Service B]
3. [Service C]

Build a cross-sell matrix:

For each core service, identify:
1. 3 complementary services
2. Why they fit (logical connection)
3. Typical upsell price
4. Best timing to introduce
5. Script opening line

Format as a table I can reference during client conversations.
```

### Prompt 3: Productized Service Designer

```
Act as a product strategist for freelance services.

My most common custom project:
- Description: [WHAT YOU BUILD]
- Typical timeline: [WEEKS]
- Typical price: $[AMOUNT]
- Common variations: [LIST]

Turn this into a productized service:
1. Service name (catchy but clear)
2. Fixed price
3. Fixed timeline
4. Standard deliverables (5-7 items)
5. Standard exclusions (3-5 items)
6. Guarantee or risk reversal
7. Sales page copy (300 words)

Make it feel premium and turnkey.
```
