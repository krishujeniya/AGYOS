# Video references and provenance

## Source toolkits

The executable packages live in [`tools/video/`](../../../tools/video/README.md), separate from
the AGYOS runbooks that describe how to use them.

## Prompt material

| File | What it contains | Provenance status |
| --- | --- | --- |
| [`nafay3d_style_prompts_recreated.md`](prompts/nafay3d_style_prompts_recreated.md) | Eight prompts newly written from publicly visible style descriptions, plus usage notes. | The file itself says these are not verbatim copies of the email-gated originals. Treat them as recreated prompts, not official source text. |
| [`creator-motion-graphics-reference.txt`](prompts/creator-motion-graphics-reference.txt) | A supplied prompt and a long embedded HTML reference for the Creator Motion Graphics style. | The original filename was `Untitled document.txt`; its author and origin were not established. Treat it as an unverified reference dump. |

These documents describe the Nafay 3D motion-graphics presets. They are separate from the six
animation styles in the faceless-shorts toolkit and its own examples. Do not merge their style
names, models, or setup instructions. Claims in a prompt are source text, not independent
verification that the referenced behavior or assets work.

The included package READMEs and any license notices are retained with the toolkits. The
recreated prompt file does not establish rights to the referenced style library, and the unverified
dump does not establish rights to its embedded reference HTML. See
[`tools/video/README.md`](../../../tools/video/README.md) for package-level licensing notes.
