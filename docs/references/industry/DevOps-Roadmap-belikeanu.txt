Build these 4 projects
Projects get you interviews. Give each one its own GitHub repo with a README, a diagram and
screenshots.



              Website on AWS
     P1       A static website on S3, created with Terraform and deployed by GitHub Actions.
               Terraform · AWS · CI/CD




              App in containers
     P2       A frontend, an API and a database running together with Docker Compose.
               Docker · Compose




              App on Kubernetes
     P3       Deploy the app with Helm, let Argo CD update it, and watch it in Grafana.
               Kubernetes · Helm · Argo CD · Grafana




              Full pipeline
     P4       Push code, run tests, build, scan with Trivy, deploy, and get an alert if it fails.
               Everything together

  ✕ Only watching videos and never building anything


  ✕ Jumping to Kubernetes before learning Linux


  ✕ Collecting certificates with no projects


  ✕ Forgetting to stop AWS resources (set a billing alarm!)


  ✕ Paying for "100% job guarantee" courses. Nobody can guarantee a job
