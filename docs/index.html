Installation and setup

Copy and paste this prompt into your coding agent (Antigravity, OpenAI Codex, Claude Code, Cursor, Windsurf, or Gemini CLI) to set up and link all 1,580+ skills automatically:

Agent prompt 
Set up and install all skills from the SKILL monorepo into my active coding agent environment:

1. Check repository:
   If not already cloned at ~/Documents/projects/SKILL, clone it:
   git clone https://github.com/krishujeniya/SKILL.git ~/Documents/projects/SKILL
   Otherwise, navigate to ~/Documents/projects/SKILL and pull the latest changes:
   cd ~/Documents/projects/SKILL && git pull origin main

2. Run skill installation and runtime linking:
   python3 ~/Documents/projects/SKILL/scripts/build_docs_data.py

3. Verify skills are active:
   Confirm that all skills (Anchor, Agent Council, Freelance Suite, ScrollHeart, Aegis, SEO Suite, Founder Suite, Gravitas, and Developer Tools) are linked into whichever agent runtime I am currently using:
   - Antigravity / AGY: ~/.gemini/skills and ~/.gemini/config/skills
   - OpenAI Codex: ~/.codex/skills
   - Claude Code: ~/.claude/skills
   - Cursor / Windsurf / Universal: ~/.agents/skills
   Print a confirmation table of the installed skills.

Anchor: Scoped orchestrator and execution runtime

Anchor is a verification system that prevents agent hallucinations, bounds mutation radius, and enforces five mandatory gates for multi-step tasks.

Core invariant: Never mark a task complete without direct validator output. If you did not run the tests, report that you did not run the tests.

The five execution gates

  1. Understand: Read target files, interface contracts, and callers before writing.
  2. Analyze: Identify dependencies, potential edge failures, and scope boundaries.
  3. Plan: Create an explicit step-by-step decision record with rollback points.
  4. Implement: Apply minimal, reversible changes inside declared write scope.
  5. Verify: Execute unit tests, type checkers, and linters. Require passing output.

Gravitas: Engineering reliability runtime

Gravitas enforces engineering discipline across all coding agents. It prevents common failure modes such as modifying code on assumed file state, claiming fixes without evidence, and looping on identical failed edits.

The six invariants

  1. Ground before mutating: Read the target file, tests, and callers before editing. Never act on assumed state.
  2. Stay in declared scope: Writes outside allowed_write_scope are denied.
  3. Completion needs evidence: A criterion is complete only when an independent validator passes after the mutation.
  4. Never exact-retry a failure: A failed action must not be repeated without changing context or approach.
  5. Satisfy the contract: Acceptance criteria in contract.json gate completion.
  6. State unverifiable claims explicitly: If an outcome cannot be tested, declare it as an unverified assumption.

Unslop writing standard

The Unslop standard removes synthetic AI vocabulary, superficial grammatical structures, and robotic formatting from documentation and user communications.

Banned AI word Plain human replacement
leverage, utilize use
delve, dive deep inspect, examine, explore
seamless, seamlessly direct, smooth, directly
robust reliable, solid
crucial, paramount essential, primary, critical
testament, tapestry proof, collection
furthermore, moreover also, in addition
