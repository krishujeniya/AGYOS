Getting Started

One prompt. Full OS.

No configuration files. No dependency installation. Paste the system prompt and every one of the 1,862 skills activates immediately.

1

Install AGY CLI

Get the Antigravity CLI runtime (agy v1.4.12+). AGYOS is the cognitive layer on top.

2

Add AGENTS.md to system prompt

Copy the AGENTS.md content into your AI agent's system prompt or place it at repository root. The 1,862 skills are now active.

3

Run any natural language task

Describe what you want. AGYOS automatically routes to the right skill, enforces TDD, and verifies the result.

4

Verify with 51-point suite

Run the adversarial verification suite to confirm all subsystems are operational and passing.

bash 
# Clone the repository
git clone https://github.com/krishujeniya/AGYOS.git
cd AGYOS

# Run adversarial verification (51 checks)
bash scripts/agyos-verify.sh

# Discover a skill
bin/agyos decide "Design Postgres schema with migrations"

# Check system state
bin/agyos state

# Convene multi-model consensus
bin/agyos council "Postgres vs SQLite for local cache?"

# Fast-path for simple edits
bin/agyos fast
bin/agyos verify

Requires: AGY CLI v1.4.12+ · Python 3.10+ · Node.js 18+ (for council) · Bun (optional, for council tests)

FastMCP Syscalls (L2)

Zero-dependency stdio JSON-RPC 2.0 state daemon exposing 7 syscalls: agyos_state, agyos_current, agyos_graph, agyos_checkpoint, agyos_find_skill, agyos_sys_info, agyos_memory.

3-Tier Memory Model (L1)

Inspired by MemGPT/Letta. Tier 0: active persona + invariants. Tier 1: recall (checkpoints, CURRENT.md). Tier 2: archival (1,862-skill catalog, paged JIT via agyos_find_skill).

Adaptive Hierarchy (L4)

Bounded tree depth ≤ 2 (3 levels: Coordinator → Pod → Leaf). Max 4 children per node. Max 3 concurrent workers. Eliminates O(N²) horizontal chatter across 5 merged corporate pods.

Governance

The 5-Gate Workflow

Every multi-step task executes sequentially through 5 programmatically locked gates. No gate can be skipped without explicit justification.

Gate 01
Understand
Clarify intent, gather requirements, document deliverables and acceptance criteria. HITL approval required before advancing.
→
Gate 02
Analyze
Read-only scope inspection. Map dependencies, risks, and boundaries. Complexity score 1–2 fast-paths; 3–5 triggers full flow.
→
Gate 03
Plan
Architecture decision records, C4 models, API contracts, data models, and test strategy. Context compaction checkpoint.
→
Gate 04
Implement
Autonomous TDD execution: write failing test (RED) → write minimal code (GREEN) → refactor cleanly (IMPROVE). 80%+ coverage enforced.
→
Gate 05
Verify
Adversarial proof of correctness. Full build, typecheck, lint, test suite + Quiz-Me gate: 3 probing questions on design, edge cases, and change impact.

Fast-Path Bypass

Complexity ≤ 2 (typos, minor edits) skips Gates 1–3 and jumps directly to IMPLEMENT → VERIFY. Triggered by bin/agyos fast.

Maker / Checker Isolation

Gate 4 (Maker) and Gate 5 (Checker) must be executed by independent subagents. No agent may approve its own pull request. Prevents self-confirming hallucinations.

Defense

Fail-Closed Security Architecture

Dual Hook System

agy_os_hook.py
PreToolUse + PostToolUse lifecycle interceptor. Blocks dangerous commands (rm -rf /, raw disk writes). Enforces 24,000-byte constitutional size budget. Fail-open: unhandled exceptions log a warning and return allow rather than deadlocking.
authorizer.py
Fail-closed authorizer for R3 irreversible actions. Stages monetary refunds, account provisioning, and destructive operations in OutboxQueue as PENDING_COMMIT until explicit operator authorization.

Risk Tiers

R0 Read-only, bounded, reversible
R1 Idempotent writes, local scope
R2 Persistent mutations, reviewable
R3 Irreversible — staged in OutboxQueue, requires explicit operator auth
ℹ Report security vulnerabilities via GitHub Private Vulnerability Reporting. Do not open public issues for security reports. Contact: Krish Ujeniya (@krishujeniya).

2. Principal Architecture — C4 model, ADRs, API contracts

4. Checker Verification — independent review + 51-point suite
Output
Production-ready code: validated inputs, idempotency keys, parameterized queries, 80%+ test coverage, zero leaked secrets.
Boundary Input Validation
Schema-first validation at every system boundary. Pydantic, Zod, Serde. HTTP 400/422 on malformed payloads.
Zero Silent Failures
No bare except or empty catch blocks. Explicit error propagation with structured error messages and correlation IDs.
Immutability Standard
Always return new copies of objects. Never mutate state in place. Functions under 50 lines. Files under 800 lines.
