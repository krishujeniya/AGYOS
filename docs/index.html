Quickstart & One-Prompt Setup

Paste this single prompt directly into your AI coding assistant (Google Antigravity agy, Claude Code, Cursor, Codex) to clone, configure, and verify AGYOS in one autonomous pass:

One-Prompt Autonomous Agent Setup 
Set up and initialize the AGYOS autonomous cognitive operating system in this workspace:
1. If not already in the repository, clone https://github.com/krishujeniya/AGYOS.git and navigate into AGYOS:
   git clone https://github.com/krishujeniya/AGYOS.git && cd AGYOS
2. Ensure executable permissions on all core binaries and scripts:
   chmod +x bin/agyos scripts/agyos-init.sh scripts/agyos-verify.sh mcp/state-server.cjs scripts/hooks/*.py
3. Run the zero-configuration bootstrapper to initialize state, validate plugins, register the FastMCP state daemon, and compile indices:
   bash scripts/agyos-init.sh
4. Execute the verification suite and unit tests to ensure all 51 automated checks pass:
   bash scripts/agyos-verify.sh
   python3 -m unittest discover -s scripts/tests -v
5. Confirm the intent compiler and 5-pod router are operational:
   bin/agyos intent "audit system security and summarize findings"
Confirm when all 51 checks pass and the workspace is fully initialized.

5-Gate Lifecycle Governance Spine

AGYOS Governance is the deterministic spine of AGYOS. It enforces five explicit gates across every development milestone to eliminate hallucinations, out-of-scope modifications, and speculative code:

Governance Invariant: Ground before mutating. Never mark a milestone complete without executing fresh machine evidence.

  1. UNDERSTAND: Clarify intent, gather requirements, document deliverables in a structured Task List.
  2. ANALYZE: AST inspection (agyos-scout), blast radius containment, complexity scoring (1-2 fast-path skips to IMPLEMENT; 3-5 full flow).
  3. PLAN: Architecture Decision Records (ADR), C4 models, test strategy, and context compaction (bin/compact.sh).
  4. IMPLEMENT: Autonomous TDD Red-Green-Refactor loop. Functions <50 lines, source files <800 lines.
  5. VERIFY: Full adversarial verification (bin/agyos verify), test ratchet monotonicity enforcement.

Security & Fail-Closed Tool Architecture

AGYOS enforces host-native tool binding aligned with Google Antigravity (agy) v1.5.0 host tools: read_file, write_file, edit_file, run_command, and search_web. All agent definitions declare only valid host tools.

Dual-Hook Architecture: Real-time pre-tool interception via authorizer.py executes synchronously before any tool invocation. Destructive or external operations are intercepted before execution.

Risk Classification Tiers

Tier Classification Host Tools Allowed Safety Policy
R0 Read-Only Inspection read_file, search_web Auto-authorized; read-only guarantees.
R1 Benign Workspace Write write_file, edit_file Authorized within declared task scope boundaries.
R2 System Execution run_command (local test/build) Authorized with command whitelisting and pre-write snapshots.
R3 Irreversible / Live External External payments, live email, remote deletes BLOCKED; held in PENDING_COMMIT outbox until signed.

State Ledger Invariants

  • Hierarchy Caps: Tree depth ≤ 2, fanout ≤ 4, workers ≤ 3, total tasks ≤ 8.
  • Kahn's Acyclicity: Task dependency graphs must be strictly acyclic DAGs.
  • Budget Guard: 30,000 tokens / $1.50 cap per task, with 20% reserved for verification.
  • Reflection Memory: Identical retries with the same error signature are blocked.
  • LIFO Saga Compensation: Rollback executes inverse actions in reverse order on failure.

Vibe-to-FAANG: Operating Model for Non-Tech Builders

AGYOS enables general builders, non-technical founders, and vibe coders to produce production-grade software without architectural rot. Users describe high-level goals in plain English, while AGYOS autonomously drives execution through Staff and Principal-level corporate engineering standards:

Operating Thesis: Vibe coders provide product vision and user requirements; AGYOS enforces contract-first architecture, test-driven development, and zero-speculation verification.

The 6 Production Invariants for Vibe Coders

  1. Boundary Input Validation: Every external payload (APIs, query parameters, webhooks) must be validated using schema contracts (Pydantic / Zod) before reaching business logic.
  2. Zero Silent Error Swallowing: Bare except: or empty promise catches are blocked. All errors must be explicitly typed and logged with telemetry.
  3. Safe & Idempotent Data Layer: Database mutations must use transactions with idempotency keys. No unbounded queries (SELECT *).
  4. Immutability & Function Ceilings: Functions must stay under 50 lines with a single responsibility. State is treated as immutable.
  5. Zero-Secret Security: Private keys, tokens, and database credentials must never be committed to source files. Environment variables are required.
  6. Deterministic Machine Evidence: No task is marked complete without passing test runs and clean compiler checks.

Emil Kowalski UI/UX & Motion Engineering Standards

Mandatory engineering standards enforced across all frontend, website, and SaaS generation workflows:

  1. Concentric Border Radii Formula: Nested child radii must satisfy R_inner = R_outer - padding to eliminate optical corner distortion.
  2. Animation Decision Framework: 100+ times/day = 0ms (no motion); tens of times/day = 150-200ms; modals/drawers = 250-350ms; never animate keyboard actions.
  3. Compositor-Only Animations: Animate ONLY transform and opacity. No layout thrashing on width/height/margin/padding.
  4. Tactile Micro-Interactions: Active scale press feedback (active:scale-[0.98]) on interactive controls. Separate hover styles via @media (hover: hover).
  5. Popover Transform Origins: Set transform-origin to the trigger button coordinates, never screen center.
  6. Before / After / Why Table: Mandatory code review table for all visual mutations.
Before After Why
transition: all 0.3s transition: transform 0.15s ease Prevents layout thrashing and geometric reflow pipeline spikes.
transform: scale(0) transform: scale(0.95); opacity: 0 Physical UI elements do not scale from a dimensionless point.
.btn:hover { background: #333; } @media (hover: hover) { .btn:hover { ... } } Prevents sticky hovered state on touch and mobile devices.

The 6 Non-Negotiable Gravitas Invariants

  1. Ground Before Mutating: Inspect existing implementations and manifests before writing code.
  2. Stay in Declared Scope: Confine file writes strictly to the active milestone path boundary.
  3. Require Machine Evidence: Never claim completion without executing fresh compiler, linter, or test output.
  4. Avoid Identical Retries: If a command fails twice with the same signature, alter the underlying hypothesis.
  5. Satisfy Contract Gates: Phase transitions must satisfy strict programmatic gate criteria.
  6. State Unverifiable Claims: Explicitly flag subjective or machine-untestable behavior.
