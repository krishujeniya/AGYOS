# AGYOS Brand & Visual Assets

This directory contains the canonical vector branding assets for AGYOS.

## Master Logo

- **File**: `assets/agyos-logo.svg`
- **Format**: Scalable Vector Graphics (SVG 1.1)
- **Design Motif**: Dark futuristic HUD geometry with an energetic cyan/blue core nucleus, layered orbital rings, coordinate crosshairs, and bold AGYOS typography with a glowing status indicator.
- **Color Palette**:
  - Background: Obsidian Deep (`#090D16`, `#040711`)
  - Accent Cyan: Electric Cyan (`#00F0FF`, `#0077FE`)
  - Border: Cyber Gray (`#1E293B`, `#334155`)
  - Typography: Pure White (`#F8FAFC`) with Cyan Glow

## Plugin Logos

Each of the 8 AGYOS plugins in `.agents/plugins/*/assets/logo.svg` contains an optimized SVG logo derived from the master vector specification.
