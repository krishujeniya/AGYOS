# SKILL Monorepo — Agent Guidelines

## Repository Structure
- `Aegis/`: Security, evaluation, and extensive skill library (1,500+ skills across community, core, experts).
- `Anchor/`: Autonomous agent orchestrator, scope manager, verification suite, and MCP server.
- `ScrollHeart/`: Cinematic scroll-driven animation skill and components.
- `agentic-freelance-skills/`: Freelance agency operations and client management skills.
- `agent-council/`: Multi-agent CLI deliberation panel (Bun / TypeScript).
- `*.pdf`: Architecture, motion graphics, and developer positioning playbooks.

## Coding & Style Standards
- Keep each module modular and self-contained.
- Follow TypeScript/Bun conventions in `agent-council/`.
- Respect Python/Node conventions in `Anchor/`.
- Ensure all skill documentation files (`SKILL.md`) adhere to standard frontmatter specifications.
