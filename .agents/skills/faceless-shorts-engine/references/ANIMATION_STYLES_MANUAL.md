# Faceless Shorts: style selection

This map summarizes the six styles named by the supplied faceless-shorts package. Each package
style has a separate STYLE.md, example project, and style sheet. Read the selected STYLE.md and
inspect its example before authoring shots; this summary does not replace those files.

| Style ID | Best fit from the supplied guide | Constraints to preserve |
|---|---|---|
| deep-dive | Stylized 3D body and science explainers | Explain causes with visible cutaways; check medical claims and avoid graphic or alarming invention. |
| night-file | Mystery and true-crime stories | Separate established facts from theories; avoid presenting speculation as a solved case. |
| inside-out | Flat 2D mechanisms and what-happens-if explanations | Keep diagrams readable and make each visual correspond to a stated mechanism. |
| stick-story | Survival scenarios and decision steps | Verify advice against authoritative sources; distinguish hypothetical choices from emergency guidance. |
| paper-atlas | Historical events, routes, and maps | Verify dates and places; paraphrase records rather than inventing quotations. |
| tall-tale | Funny or surprising true stories | Preserve the factual sequence; do not invent dialogue or evidence to improve a punchline. |

The source examples describe different palettes, characters, caption treatments, and sound cues.
Treat those as style-specific implementation constraints, not universal requirements. Do not imitate
a creator's exact shots, scripts, logos, or distinctive character designs. Build original scenes
from high-level visual traits and the user's content.

For a new style, ask for references and separate visible details from inferred motion. A still image
does not prove how animation behaves.
