## 1. The "YES" Confirmation

### The Email Confirmation

```
Subject: [Project Name] — Let's Get Started!

Hi [Name],

Fantastic! I'm excited to work with [Company] on [project].

Here's what happens next:

1. **SOW Attached:** Please review and reply "YES" to confirm
2. **Deposit Invoice:** I'll send within 24 hours of your confirmation
3. **Kickoff Call:** We'll schedule for [day after deposit received]
4. **Project Portal:** I'll set up [Notion/Slack/Trello] for updates

**Project Summary:**
- Scope: [Brief description]
- Timeline: [Weeks] (kickoff [date] → delivery [date])
- Investment: $[Amount] (50% deposit + 25% milestone + 25% final)
- My direct email: [your email]
- Emergency contact: [your phone]

**What I need from you before kickoff:**
- [ ] Data access credentials
- [ ] Brand guidelines (if applicable)
- [ ] Stakeholder contact list
- [ ] Any existing documentation

Questions? Just reply to this email.

Let's build something great.

Best,
[Your name]
```

### The Mutual Agreement "YES" [Him Singh Style]

For smaller projects or fast-moving clients:

```
Subject: [Client] x [Your Name] | Mutual Agreement for [Project]

Hi [Name],

So this is a mutual agreement for partnership between [Client] and 
us on delivering [specific work].

Under this agreement we mutually agree on:

We provide:
1) [Deliverable 1] — [specification]
2) [Deliverable 2] — [specification]
3) [Deliverable 3] — [specification]
4) [X] revision rounds free of cost
5) Additional revisions at $[Amount] each
6) Payments: [upfront/milestone]
7) Delivered by [date]

You provide:
1) [Client responsibility 1]
2) [Client responsibility 2]

Kindly reply "YES" to confirm and agree.

If you have any questions, feel free to ask.

Cheers,
[Your name]
```

## 3. Kickoff Ritual

### The Kickoff Call Agenda (30 minutes)

| Time | Topic | Purpose |
|------|-------|---------|
| **0-5 min** | Introductions + rapport | Build comfort |
| **5-10 min** | Review SOW + success criteria | Align on expectations |
| **10-15 min** | Access + logistics | Remove blockers |
| **15-20 min** | Communication norms | Set boundaries |
| **20-25 min** | Q&A | Address concerns |
| **25-30 min** | Next steps + calendar | Lock in timeline |

### Communication Norms Setup

```
"To make sure this runs smoothly, here are my communication norms:

• **Updates:** Every [Tuesday/Friday] via [email/Slack]
• **Response time:** Within 24 hours on business days
• **Urgent issues:** Text/call [number] — I'll respond within 2 hours
• **Feedback:** Please provide within 48 hours of delivery
• **Scope changes:** Email only — no Slack scope creep

Does this work for your team?"
```

### The Project Portal Setup

**Tools:** Notion, Trello, Linear, Asana, ClickUp

**Portal Contents:**
- [ ] Project overview + SOW
- [ ] Timeline with milestones
- [ ] Deliverables tracker
- [ ] Meeting notes archive
- [ ] Resource folder (brand assets, data access)
- [ ] FAQ / Decision log

## 5. Payment Protection

### The Deposit Rule

| Project Size | Deposit % | When Due |
|--------------|-----------|----------|
| Under $2,000 | 100% upfront | Before work begins |
| $2,000-$10,000 | 50% upfront | Before work begins |
| $10,000-$25,000 | 50% upfront + 25% milestone | Milestone defined in SOW |
| Over $25,000 | 33/33/33 | Start, midpoint, delivery |

### The Milestone Rule

Never deliver final work before final payment:

```
"The final deliverables will be transferred upon receipt of 
final payment. You'll receive:
• Full source code
• Documentation
• Deployment credentials
• Training materials

Once payment is confirmed, I'll send everything within 
2 hours."
```

### Escalation for Non-Payment

| Stage | Action | Timeline |
|-------|--------|----------|
| **1. Friendly** | Email reminder + phone call | Day 3 past due |
| **2. Formal** | Written notice referencing SOW | Day 7 past due |
| **3. Pause** | Stop all work, notify of delay | Day 10 past due |
| **4. Final** | Demand letter, mention legal | Day 21 past due |
| **5. Legal** | Small claims or collections | Day 30+ past due |

**Prevention > Cure:**
- Always get deposit before starting
- Use milestone payments for large projects
- Include late fees in SOW
- Keep communication documented
- Know when to walk away (sunk cost fallacy)

## 6. AI Prompts

### Prompt 1: Closing Email Writer

```
Act as a client onboarding specialist.

Project details:
- Client: [COMPANY]
- Project: [NAME]
- Price: $[AMOUNT]
- Timeline: [WEEKS]
- Payment: [STRUCTURE]

Write a closing email that:
1. Celebrates the "yes" (enthusiastic but professional)
2. Lists 4-5 clear next steps
3. Includes what client needs to provide
4. Sets communication expectations
5. Attaches SOW (reference it)
6. Ends with forward momentum

Tone: Excited, organized, professional.
```

### Prompt 2: Invoice Generator

```
Act as a billing specialist for freelancers.

Invoice details:
- Invoice #: [NUMBER]
- Client: [COMPANY]
- Project: [NAME]
- Amount: $[AMOUNT]
- Description: [WHAT THIS PAYMENT IS FOR]
- Payment methods: [PAYONEER/WISE/BANK]

Generate:
1. Professional invoice (formatted)
2. Payment request email
3. Payment reminder (day 3 past due)
4. Final notice (day 14 past due)

Make it clean, professional, and legally sound.
```

### Prompt 3: Kickoff Agenda Creator

```
Act as a project manager.

Project type: [AI/ML / Web Dev / Data / etc]
Client: [COMPANY TYPE]
Team size: [NUMBER]
Duration: [WEEKS]

Create a kickoff meeting agenda:
1. 30-minute structured agenda (minute-by-minute)
2. 5 questions to ask the client
3. 3 things to communicate about your process
4. 2 potential concerns to surface early
5. Follow-up email template

Make it specific to [project type], not generic.
```

## 7. Action Checklist

### Day 1: Confirmation

- [ ] Send "YES" confirmation email
- [ ] Attach SOW (if not already sent)
- [ ] Send deposit invoice within 24 hours
- [ ] Set up project portal (Notion/Trello/Slack)
- [ ] Calendar kickoff call (after deposit)

### Day 2-3: Preparation

- [ ] Confirm deposit received
- [ ] Send kickoff meeting invite
- [ ] Prepare kickoff agenda
- [ ] Set up project tracking system
- [ ] Create folder structure for deliverables

### Day 4-7: Kickoff

- [ ] Conduct kickoff call (use agenda)
- [ ] Document meeting notes
- [ ] Confirm client provided all access/logistics
- [ ] Send summary email with next steps
- [ ] Begin work (if all blockers cleared)

### Ongoing: Financial Hygiene

- [ ] Send invoices on schedule (milestone dates)
- [ ] Track payment status in spreadsheet
- [ ] Follow up on late payments (3-day rule)
- [ ] Reconcile payments monthly
- [ ] Save all invoices for tax purposes
