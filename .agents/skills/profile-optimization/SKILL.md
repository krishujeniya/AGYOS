  Use to optimize a social media profile so it converts visitors into followers and followers into
  leads — bio, handle, name/headline field, profile picture, banner/header, link-in-bio, CTA, pinned
  posts, and highlights. Run when the user says "optimize my profile/bio," "write my bio," "my
  Instagram/LinkedIn/TikTok bio," "profile," "link in bio," "my profile isn't converting," asks
  about creator mode or a professional/business account, or wants their account to convert better.
  Reads brand-profile, voice, audience, and social-strategy first. Treats the profile as a
  conversion landing page — 3-second clarity, searchable-field keywords, a who/what/why bio with one
  CTA, a goal-matched link, and specs for the visuals, pinned posts, and highlights. Advisory:
  produces a ready-to-apply per-platform spec (WoopSocial publishes posts/media; it does not edit
  profile fields). Judges results via native profile insights, not WoopSocial analytics.

  - "# Profile Optimization\n\nYour profile is a **conversion landing page, not decoration.** Content earns reach and sends a\ncurious stranger to your profile — and the *profile* is where that visit converts to a follow, and a\nfollow to a lead. Most accounts pour everything into content and leave a vague, leaking profile, so\nthe visits never convert. A blunt diagnostic: **lots of profile visits but few follows/clicks is\nusually the bio, not the algorithm.**\n\nTwo commitments:\n\n1. **Clarity beats cleverness.** A visitor decides in seconds. Above the fold the profile must answer\n   **who you help, what you do, why follow** — instantly. A witty-but-vague bio converts worse than a\n   plain, specific one.\n2. **Every element has a job.** The name field is *searchable*. The link is the *conversion\n   mechanism*. The banner is *prime real estate*. \"Filled in\" isn't optimized.\n\n> Scope: this skill is **advisory** — it produces a ready-to-apply spec. **WoopSocial publishes posts\n> and media; it does not edit profile fields**, so the user applies the spec in each app.\n\n"
  - "## Step 0 — Read the foundation\n\nLoad `brand-profile.md`, `social-strategy.md`, `audience.md`, `voice.md`. The profile is positioning\nmade concrete: who you help + the wedge (brand/strategy), the audience's language (audience), the\nprimary goal → the CTA/link (strategy), and the tone (voice).\n\n"
  - "## Step 1 — Run the funnel + the 3-second test\n\nDiagnose the profile as a funnel — **Discovered → Clarity → Follow → Convert** — and find which stage\nleaks (unfindable / unclear / unconvincing / dead-end). Make sure the above-the-fold answers\nwho/what/why at a glance. Niche down — **\"for everyone\" converts no one.** See\n`references/the-profile-funnel.md`.\n\n"
  - "## Step 2 — Exploit the searchable fields (get discovered)\n\nPut a **niche keyword** in the searchable fields — the **Instagram name field**, the **LinkedIn\nheadline**, the **YouTube description** — not just your name or \"Founder.\" Think like your audience:\nwhat would they search? Keep the handle searchable and consistent. See `references/element-playbook.md`.\n\n"
  - "## Step 3 — Write the bio (earn the follow)\n\nWho you help · what you do · **proof** (real only) · **CTA + link prompt** — clarity first,\npersonality second, skimmable, within the limit, on-voice. See `references/element-playbook.md`.\n\n"
  - "## Step 4 — The link + CTA (convert)\n\n**Match the link to the current goal** (one clear destination beats a 15-link junk drawer; if you\nneed a hub, lead with the priority action). Pick **one** primary CTA. Make the bio say *why* to click.\nFor the full link-in-bio page strategy and traffic measurement, hand off to `link-in-bio-and-traffic`\n— this skill decides *which* link the profile carries.\n\n"
  - "## Step 5 — The visual + first impression\n\nProfile **picture** (face for personal brands, clean logo for companies; recognizable at thumbnail).\n**Banner/header** brief (value prop / proof / CTA — never a stock photo); hand the visual to a\ndesigner or `tools/integrations/ideogram.md` (legible text). **Pinned/featured** posts and\n**highlights** to control the first impression (Start here / Proof / Offer / FAQ).\n\n"
  - "## Step 6 — Per-platform spec + consistency\n\nProduce a **ready-to-paste spec per platform** (handle, name field, bio, link, CTA, pinned plan,\nhighlights, banner brief), each passing the 3-second test. Keep handle/pic/positioning **consistent**\nacross platforms; **re-fit** the bio per platform (limits, searchable fields). See\n`references/platform-specs.md`.\n\n"
  - "## Quality bar — self-check\n\n- Does it pass the **3-second test** (who/what/why above the fold)?\n- Are the **searchable fields** used for keywords (name field / headline)?\n- Is the bio **clear, specific, proof-backed, with one CTA**, on-voice, within the limit?\n- Is the **link matched to the goal** (not a junk drawer)?\n- Are **pinned/highlights/banner** specced (not left default/stock)?\n- Is it **niched** (not \"for everyone\")?\n- Is it delivered as an **advisory spec**, with **no fabricated proof** and **no analytics claims**?\n\n"
  - "## Edge cases & pushback\n\n- **Vague/clever bio** (\"dream big ✨\") → rewrite for who/what/why clarity.\n- **Wasting searchable fields** (name = just name; headline = \"Founder\") → add a niche keyword.\n- **One link doing five jobs** → match to the goal or a hub that leads with the priority.\n- **\"Appeal to everyone\"** → niche down; for-everyone converts no one.\n- **Stock-photo banner** → a banner brief carrying value prop/proof/CTA.\n- **New account, no proof** → clarity + specificity + niche; never fabricate numbers/testimonials.\n- **\"Just change it for me\"** → can't edit profiles via WoopSocial; deliver the spec to apply.\n- **\"Which bio performs best?\"** → native profile insights / the 3-second test; no WoopSocial\n  analytics.\n\n"
