  - "# Engagement Routine\n\nThe **operating system** for engagement. `reply-and-comment-writer` is the *craft* (what to say);\nthis is the *cadence* (when, how much, in what order, sustainably). The growth skills all call for \"an\nengagement routine\" — this is it.\n\nThe data is blunt: **replying is the highest-return activity on every platform**, the **first ~15–20\nminutes** after posting matter most, and **comments/DMs outweigh likes.** But it only works as a\n**habit** — and the habit only survives if it's **sustainable** (≈46% of social pros have considered\nquitting over stress). So this skill optimizes for **return *and* longevity.**\n\n"
  - "## Step 0 — Read the context\n\nLoad `brand-profile.md` / `social-strategy.md`: who the ICP is, which platforms actually matter, and\nhow much time the user realistically has. Right-size everything to that.\n\n"
  - "## Step 1 — Set the cadence (windows, not all-day)\n\nDesign **time-boxed engagement windows** instead of all-day grazing — e.g. **~20 min morning + ~20 min\nafternoon**, plus a **golden-hour pass** right after each post publishes. Order within each window:\n**comments → DMs → urgent/negative → proactive comments** on ICP/peers/leaders. See\n`references/the-daily-and-weekly-routine.md`.\n\n"
  - "## Step 2 — Free the time (the flywheel)\n\n\"No time to engage\" is solved by **batching + scheduling content** (→ `batch-content-plan`,\n`scheduling-and-queue`) to reclaim the hours, then spending them engaging. The flywheel: **schedule →\nfreed time → genuine engagement → reach/relationships → more reach.** Time posts for windows you can be\npresent. See `references/the-scheduling-engagement-flywheel.md`.\n\n"
  - "## Step 3 — Triage & aim at a goal\n\nWhen time is short, do the **highest-return things first** (golden-hour comments → DMs → negative →\nproactive), focus on **the right people (ICP/peers), not vanity volume**, and map the routine to a\n**goal** with 2–3 meaningful signals you can read **natively** (no WoopSocial analytics). See\n`references/triage-priorities-and-goals.md`.\n\n"
  - "## Step 4 — Make it sustainable\n\nBuild in **boundaries**: notification discipline, **set + communicate response windows**, protect\noff-hours, and prefer a **small repeatable routine you keep** over a heroic one you abandon.\n**Consistency at a holdable pace** beats sprints. See `references/sustainability-and-boundaries.md`.\n\n"
  - "## How it runs (advisory + honest)\n\n- **WoopSocial has no inbox.** It **publishes/schedules** (the flywheel's first half); it\n  **cannot pull comments/DMs or post replies.** Post performance for the covered platforms is\n  `analytics-and-reporting`, not this skill, and it cannot name a best time. The **human engages in-app** via\n  native notifications; the **agent drafts** replies/comments (→ `reply-and-comment-writer`).\n- **Genuine only.** No automation, bots, mass auto-comments, or bought/fake engagement — detected,\n  penalized, self-defeating. The agent assists by drafting; the human does the real interacting.\n\n"
  - "## Quality bar — self-check\n\n- Did I design a **concrete, time-boxed** daily + weekly cadence, centered on the **golden hour**?\n- Did I use the **flywheel** (schedule to free the time) and right-size to the user's **time/platforms**?\n- Did I give a **triage order**, aim at a **goal with native signals** (no fabricated analytics), and\n  focus on **the right people**?\n- Did I make it **sustainable** (boundaries, response windows, not always-on)?\n- Did I keep it **advisory** (human engages in-app, agent drafts) and **genuine** (no automation/fake)?\n\n"
  - "## Edge cases & pushback\n\n- **\"Auto-reply / mass-comment for me\"** → refuse automation/fake; genuine routine + draft-for-review.\n- **\"WoopSocial: pull my comments + tell me the best time\"** → no inbox, and post analytics are not a timing model; native inbox +\n  agent drafts.\n- **\"No time to engage\"** → batch + schedule to free time (the flywheel); don't engage less.\n- **\"Reply to everyone everywhere\"** → triage + the right people; done beats perfect.\n- **\"I'm burning out checking all day\"** → windows + notification discipline + response boundaries.\n- **\"How do I know it's working?\"** → goal + native signals (comment depth, DM convos); no vanity, no\n  fabricated numbers.\n\n"
