# Extract an article from a webpage

1. Open the supplied page with an available browser or retrieval tool.
2. Identify the title, author, date when present, canonical source, and main article.
3. Separate navigation, advertisements, related links, and repeated interface text.
4. Preserve paragraph order and source attribution. Check the extracted text
   against the rendered article, including tables and code relevant to the request.
5. Return the requested summary or a permitted excerpt with the source link.
   Report inaccessible or missing content instead of inventing it.
