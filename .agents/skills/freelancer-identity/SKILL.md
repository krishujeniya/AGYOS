  - "## Agent Guidelines & Workflows\n\n"
  - "### 1. Personal Branding\nWhen asked to define a freelancer's brand or positioning:\n- Reference [01A-PERSONAL-BRAND.md](references/01A-PERSONAL-BRAND.md) to audit their **Trust Triangle** (Competence, Credibility, Reliability).\n- Help them construct a formal **Brand Promise Statement**: *\"I help [ideal client] achieve [specific outcome] through [unique mechanism].\"*\n- Define their **Anti-Positioning** boundaries (what they do *not* do) to clarify expertise and shield against scope creep.\n\n"
  - "### 2. LinkedIn Profile Optimization\nWhen asked to write or improve a LinkedIn profile:\n- Reference [01B-LINKEDIN-OPTIMIZATION.md](references/01B-LINKEDIN-OPTIMIZATION.md) to apply the **7-Second Profile Test**.\n- Write a 220-character headline following the formula: `[Role / Core Niche] + [Outcome / High-Value Result] + [Trust Anchor / Proof] + [Call to Action]`.\n- Structure the About section with hook-driven narrative copywriting, value pillars, and a clear call to action.\n- Guide them through the **15-15-15 outbound prospecting ritual** (15 DMs, 15 Comments, 15 Connections daily).\n\n"
  - "### 3. Portfolio Case Studies\nWhen asked to write a case study or design a portfolio page:\n- Reference [01C-PORTFOLIO-POSITIONING.md](references/01C-PORTFOLIO-POSITIONING.md) to structure projects using the **STAR-M Case Study Template** (Situation, Task, Action, Result, Metrics).\n- Ensure case studies emphasize business outcomes and hard metrics (revenue, speed, accuracy) over tutorial-style descriptions.\n- Set up a three-tiered **Good-Better-Best service matrix** (Starter, Professional, Enterprise) to maximize project deal size.\n\n---\n\n"
